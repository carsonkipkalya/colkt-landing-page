# Colkt Landing Page

The official landing page for **Colkt**, a personal media library for collecting, organizing, tracking, and enjoying movies, TV shows, and books in one place.

## Overview

This website introduces Colkt, explains its core features, shares development progress, and gives visitors a way to join the pre-launch waitlist.

## Sections

- **Hero** — Introduces Colkt and invites visitors to join the waitlist.
- **About** — Explains what Colkt is and the problem it aims to solve.
- **Features** — Highlights the main product capabilities through descriptions and interface previews.
- **Values** — Communicates the project's approach to privacy, ownership, accessibility, and open source.
- **Project Progress** — Shares development updates and links to project resources.
- **Waitlist** — Collects email addresses from people interested in following the launch.
- **Footer** — Provides navigation, project links, and relevant legal information.

## Purpose

The landing page serves as Colkt's public introduction and pre-launch home. Its main goals are to:

- Explain the product clearly.
- Showcase its planned features and interface.
- Build early interest in the project.
- Collect waitlist registrations.
- Direct visitors to the source code, documentation, and other project resources.

## Tech Stack

- **HTML5** – Page structure and semantic markup.
- **CSS3** – Styling, responsive layouts, and animations.

## Status

The landing page is part of Colkt's pre-launch development. Content, features, and project links may change as development progresses.
